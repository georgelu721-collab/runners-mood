# Runner's Mood

**Meet them at mile one.** Runner's Mood is a concept app that matches you with people you've actually run with. After a run club run, you privately signal your mood (a running buddy, a crew, or a date) and only connect when it's mutual. Matches settle on the gentler mood, so nobody gets rejected in front of the club.

## View the site locally

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

To host it, enable GitHub Pages for this repo (Settings → Pages → deploy from branch, root folder).
